# 电子书基础卡片需求规格说明书

## 定位

电子书基础卡片用于在薯片卡片文件中保存电子书资源。它只负责资源导入、资源保存、元数据编辑、查看态展示和资源打开意图传递；实际阅读能力由阅读器或图片查看器类应用插件承担。

## 资源类型

- 普通电子书：EPUB/EPUB3、PDF、TXT/Markdown、MOBI、AZW/AZW3、FB2、DJVU 等格式作为卡片根目录内部资源保存。
- 图片包：仅支持 ZIP/CBZ。上传后不得保存原压缩包，必须解包并只保留可识别图片，非图片条目丢弃。

## 编辑能力

- 提供一个主上传入口，同时接受普通电子书与 ZIP/CBZ 图片包。
- 提供封面上传入口，用户上传封面后覆盖自动封面。
- 提供书籍名称与书籍作者输入框。
- 当来源为图片包时，提供图片排序依据选择：文件名或 ZIP 条目时间。
- 上传 EPUB 时尽力解析书名、作者与封面。解析不到时字段保持空字符串，由 UI 占位文案表达。
- 上传图片包后通过宿主 `importArchiveBundle(...)` 完成解包、图片过滤、目录落位和 ZIP 条目元数据返回，再按排序规则生成 `image_sequence`，默认第一张为封面。

## 查看能力

- 展示封面、书名、作者、格式或图片数量。
- 普通电子书点击后通过 `openResource(...)` 传递电子书资源与 `chips.book-card` payload。
- 图片包点击后以第一张图片作为主资源，同时在 payload 中按顺序传递全部图片资源描述，图片查看器应据此浏览完整图包。

## 资源与持久化

- 内部资源路径只保存卡片根目录相对路径。
- `collectResourcePaths` 必须返回 `book_file`、`cover_image`、`image_sequence[*].file_path` 与 `resource_paths` 中的有效路径。
- 替换电子书、封面或图片包时，旧资源必须通过 `deleteResource` 登记删除。
- 插件不得直接访问 Host、内核或文件系统内部实现。

- `npm test` 通过，覆盖 schema、ZIP、EPUB、编辑器、查看态与集成刷新。
- `npm run build` 通过。
- `npm run validate` 通过。
- `npm run package` 通过。
- `npm run verify` 完整串联通过。
