# 超链接基础卡片插件说明

## 定位

超链接基础卡片用于在复合卡片中插入一个可点击链接。插件入口对外声明 `base.hyperlink`，内容配置中的 `card_type` 固定为 `HyperlinkCard`，并通过 `basecardDefinition.aliases` 与正式卡片类型建立映射。

## 配置字段

- `anchor_text`：锚文本，必填，显示为查看态长条按钮文字。
- `url`：跳转链接，必填，只接受 `http` 与 `https` 地址。
- `theme`：主题变体标识，空字符串表示跟随当前主题。
- `locale`：插件文案语言，默认 `zh-CN`。

## 运行时行为

- 查看态渲染一个全宽长条形描边按钮，按钮样式只使用主题 token 和透明背景。
- 有效链接点击时优先调用基础卡片查看态上下文中的 `openResource(...)`，由复合卡片壳层转发为 `chips.composite:resource-open`，再由卡片查看器调用 `resource.open` 交给用户系统默认浏览器打开。
- 若运行环境直接注入 `window.chips`，插件会回退调用 `transfer.openExternal`；不再使用 iframe 内的 `window.open`，避免 sandbox 阻断弹窗。
- 无效或缺失链接渲染为不可点击的同形态描边条，避免把不安全地址写入可点击入口。
- 编辑引擎预览态通过 `previewPointerEvents: "shielded"` 把点击交给外层选择层，防止编辑时误打开外链。

## 资源与权限

本插件不导入、不引用卡片根目录内部资源，`collectResourcePaths()` 固定返回空数组。查看态点击外链需要 Host 外部打开能力，`manifest.yaml` 声明 `platform.external` 权限。
