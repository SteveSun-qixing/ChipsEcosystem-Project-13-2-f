# 认证与会话链路

## 1. 背景

客户端运行在 Host 渲染进程（`file://` / `chips-render://`），无法读取社区服务器写入的 HttpOnly Cookie。因此客户端使用社区平台 API 契约 v1.3 的客户端认证口径：

- 登录 / 注册响应体同时返回 `accessToken` 与 `refreshToken`；
- 客户端安全保存 `refreshToken`，会话恢复与 401 刷新通过请求体提交 `refreshToken`；
- 公开契约见 `生态共用技术文档/协议与契约/09-社区平台API契约.md` 第 2 节。

## 2. 凭据存储

| 凭据 | 存储位置 | 说明 |
| --- | --- | --- |
| `accessToken` | 内存（`src/community/api/client.ts`） | 每次请求写入 `Authorization: Bearer` 头 |
| `refreshToken` | Host credential，ref = `community.refreshToken` | 经 `client.credential.set/get/delete` 安全存取（需 `credential.manage` 权限） |

常量定义在 `src/community/lib/server-config.ts`：

- `COMMUNITY_SERVER_URL_CONFIG_KEY = "community.server.baseUrl"`
- `COMMUNITY_REFRESH_TOKEN_REF = "community.refreshToken"`

## 3. 链路流程

### 3.1 登录 / 注册

1. `authApi.login / register` 调用 `POST /api/v1/auth/login | register`；
2. 响应中的 `accessToken` 写入内存，`refreshToken` 返回给 `AuthContext`；
3. `AuthContext.login / register` 调用 `saveStoredRefreshToken(client, refreshToken)` 持久化到 Host credential；
4. `setUser(profile)` 更新界面登录态。

### 3.2 启动会话恢复（AuthContext.tryRestore）

1. 读取 Host credential 中的 `refreshToken`；
2. 若不存在 → 未登录；
3. 存在 → `POST /api/v1/auth/refresh`，请求体 `{ refreshToken }`；
4. `204` 或非 200 → 未登录；否则取 `data.accessToken` 写入内存；
5. `GET /api/v1/users/me` 获取用户资料完成恢复。

### 3.3 401 自动刷新（apiClient）

1. 业务请求返回 `401` 且未重试过 → 调用 `tryRefreshToken()`；
2. `tryRefreshToken` 通过 `setRefreshTokenReader` 绑定的读取器从 Host credential 取 `refreshToken`；
3. `POST /api/v1/auth/refresh`（请求体 `{ refreshToken }`）成功后用新 token 重放原请求；
4. 并发 401 由 `isRefreshing + refreshQueue` 合并，避免重复刷新；
5. 刷新失败或 `204` → 清空内存 token，业务侧抛出 `AUTH_TOKEN_EXPIRED`。

### 3.4 退出登录

1. `POST /api/v1/auth/logout`（尽力而为，失败不阻断）；
2. 删除 Host credential 中的 `refreshToken`；
3. 清空内存 token 与用户状态。

## 4. 相关文件

- `src/community/api/client.ts`：请求封装、token 刷新队列、`configureCommunityApiBaseUrl / setRefreshTokenReader`。
- `src/community/api/auth.ts`：认证领域 API。
- `src/community/contexts/AuthContext.tsx`：会话状态机与恢复逻辑。
- `src/community/lib/server-config.ts`：凭据与服务器地址存取。
- `src/runtime/community-runtime.ts`：`bindCommunityRuntime` 统一绑定刷新读取器。
