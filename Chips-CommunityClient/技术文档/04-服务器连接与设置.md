# 服务器连接与设置

## 1. 服务器地址配置

- 默认地址：`https://www.chipscard.space`（`config/app-config.ts` 的 `communityServerUrl`）；
- 持久化：Host `config` 键 `community.server.baseUrl`（`client.config.set`，需 `config.write` 权限）；
- 启动引导：`CommunityBootstrap` 读取配置并调用 `configureCommunityApiBaseUrl`，之后所有 API 请求基于该地址；
- 设置页（`/settings`，`src/community/pages/SettingsPage.tsx`）可修改地址：
  - 输入校验 `normalizeCommunityServerUrl`（仅接受 http/https，去尾斜杠）；
  - 保存后立即生效并持久化。

## 2. CORS 与 CSP

- 社区服务器生产模式放行 `chips-render:` 前缀 Origin、`null` Origin 与 `CORS_EXTRA_ORIGINS` 白名单（见社区平台 API 契约 1.5 节，工单125 已收口）；
- 客户端入口页 CSP `connect-src` 放行 `http:` / `https:` / `file:` / `blob:`，以支持配置任意社区服务器地址；
- `img-src` 与 `frame-src` 放行远程资源，支持卡片封面（HTML 封面 iframe）与资源图片加载。

## 3. 设置页内容

| 区块 | 行为 |
| --- | --- |
| 服务器地址 | 输入 + 保存，保存结果反馈 |
| 语言切换 | 调用 `runtime.setLocale`（zh-CN / en-US） |
| 账号 | 显示当前登录用户；未登录提供登录入口；已登录可退出（`platform.showConfirm` 确认后走 02 文档退出链路） |

## 4. 安全说明

- `refreshToken` 存 Host credential（加密落盘），不进入页面本地存储；
- 上传 / 下载 / 打开会话的 accessToken 由内存持有，随模块调用输入传递；
- 不在客户端保存社区账号密码。
