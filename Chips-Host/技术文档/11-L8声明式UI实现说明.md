# L8 声明式 UI 实现说明

> 文档状态：已实现  
> 适用范围：Host 内置运行时 L8（`src/renderer/declarative-ui/*`）

---

## 1. 实现范围

本次实现覆盖架构手册中 L8 的四类交付要求：

- 语义原语：`View`、`Stack`、`Grid`、`Form`、`List`、`Section`、`ScrollView`、`Text`、`Image`、`Media`、`Table`、`Navigation`、`Toolbar`、`Command`、`Slot`
- 声明树节点模型：`id/type/props/state/bindings/events/themeScope/modifiers/children`
- Modifier 模型：`themeScope/i18nKey/layout/accessibility/focusScope/shortcut/permission/presentation/motion/testId`
- 组合模式规范：Compound Components + slot schema + 结构化诊断 + boolean 模式守卫
- 事件与副作用模型：`ui-effect/runtime-effect/telemetry-effect` 分级与渲染阶段约束

## 3. 关键约束落实

### 3.1 节点模型约束

- `createUINode` 对 `id/type` 执行非空校验，非法输入直接拒绝。
- `cloneUINode` 深层递归克隆，避免外部状态共享污染。
- `props/state` 必须是可序列化 plain object；`props` 会拒绝视觉硬编码字段。
- `bindings/events` 只允许非空字符串映射，禁止函数、对象实例或可执行载荷进入声明树。

### 3.2 Modifier 约束

- `modifiers.themeScope` 与顶层 `themeScope` 同步归一；两者同时存在且不一致时拒绝创建节点。
- `layout/accessibility/focusScope/shortcut/permission/presentation/motion` 均按白名单字段校验。
- `shortcut` 只保存快捷键到 command id 的声明绑定，不执行命令实现。
- `permission` 只声明 action/resource/fallback，不直接访问 Host 服务。
- `motion` 只保存语义 preset 或阶段名称，不写 CSS 动画值。
- 新增错误码：
  - `DECLARATIVE_UI_MODIFIER_INVALID`
  - `DECLARATIVE_UI_VISUAL_PROP_FORBIDDEN`

### 3.3 组合模式约束

- `createCompoundComponent` 使用显式 slot 定义组件结构。
- slot 支持 `required/type/multiple/part/role/description` schema。
- `StandardCompoundSlotSchemas` 提供 `Dialog/Tabs/Menu/Form/DataGrid` 标准复杂组件 schema。
- `CompoundComponent.validate()` 可返回结构化 `DeclarativeUIDiagnostic`，包含 `nodeId/type/path/stage/severity/code/message/suggestion/details`。
- `compose()` 在结构化诊断出现 error 时抛出对应 `DECLARATIVE_UI_*` 错误。
- `guardAgainstBooleanModeProps` 默认阻断 `is/has/show/with*` 布尔模式扩张。
- 复合组件 root 支持透传 `modifiers`，slot 子节点继续走 `createUINode` 统一校验。

### 3.4 事件与副作用约束

- 事件声明仅保存 handlerId，实际执行器由 `EventBindingRegistry` 管理。
- `validateNodeEventBindings` 可递归检查声明树事件绑定，并在不执行 handler 的前提下输出结构化诊断。
- `EffectDispatcher` 对 `runtime-effect + render` 组合强制报错：
  - `DECLARATIVE_UI_RUNTIME_EFFECT_FORBIDDEN_IN_RENDER`
- 若需要渲染后执行，必须走 `schedule()` + `flushScheduledRuntimeEffects()`。

## 4. 对外可用接口（摘要）

- 原语：`View/Stack/Grid/Form/List/Section/ScrollView/Text/Image/Media/Table/Navigation/Toolbar/Command/Slot`
- 节点工具：`createUINode/cloneUINode/bindNodeEvent/appendChildren/withNodeModifiers`
- 组合工具：`createCompoundComponent/guardAgainstBooleanModeProps`
- 标准 schema：`StandardCompoundSlotSchemas`
- effect 工具：`createUIEffect/createRuntimeEffect/createTelemetryEffect/EffectDispatcher`
- 事件工具：`EventBindingRegistry/validateNodeEventBindings`
