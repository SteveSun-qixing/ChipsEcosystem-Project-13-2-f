# 工单098：社区卡片发布链路缺少本地端处理与对象存储直传契约

## 背景

社区服务器当前已经提供网页端可用的卡片和箱子上传接口，本地工具也可以登录后复用这些 HTTP 接口上传 `.card` / `.box` 文件。

用户进一步明确希望官方本地上传工具承担卡片资源发布预处理：在用户设备上解包卡片、上传卡片内部资源到资源服务器、替换资源链接、重新打包处理后的 `.card`，再把这个处理后的 `.card` 提交给社区服务器。这样社区服务器不需要承担大文件资源中转与资源链接替换压力，尤其适合社区服务器带宽有限的部署场景。

用户同时明确：本地上传器阶段不需要执行 HTML / 封面 HTML 转换；后续如果社区查看、搜索索引或静态预览仍需要转换，应由社区服务器在需要时转换。

## 证据

1. `Chips-CommunityPlatformServer/packages/server/src/routes/upload.ts` 中，`POST /api/v1/upload/card` 使用 `fastify.authenticate` 保护，说明本地工具可以通过账号登录后的 Bearer Token 调用。
2. 同一路由会把 multipart 上传流写入社区服务器临时文件，再创建数据库记录并异步调用 `runCardPipeline(...)`。
3. `Chips-CommunityPlatformServer/packages/server/src/pipeline/card-pipeline.ts` 中，服务端流水线负责解包、富文本文件内容内联、资源上传、URL 替换、重新打包、HTML 转换、封面 HTML 输出、上传 HTML 目录和更新数据库。
4. `Chips-CommunityPlatformServer/packages/server/src/storage/s3.ts` 中，对象存储写入使用服务端环境变量中的 S3 凭证，并通过服务端 `PutObjectCommand` 上传。
5. 当前代码与文档未发现预签名上传 URL、STS 临时凭证、客户端上传会话、资源清单确认或本地端发布提交接口。

## 影响范围

- 社区服务器上传 API 与卡片发布流水线；
- 官方本地上传器 / 桌面发布工具；
- Host / SDK 中卡片解包、资源重写、卡片打包能力的复用边界；
- 对象存储资源归属、权限、配额和清理机制；
- 社区平台 API 公共契约、错误码、上传任务状态机和运维部署说明；
- 社区服务器带宽、CPU、磁盘临时空间与转换插件运行负载。

## 复现步骤

1. 调用 `POST /api/v1/auth/login` 获取 `accessToken`。
2. 使用 `Authorization: Bearer <accessToken>` 调用 `POST /api/v1/upload/card` 上传 `.card`。
3. 观察 `upload.ts` 会先把完整上传内容写入社区服务器临时目录。
4. 观察 `card-pipeline.ts` 会在服务器端完成资源上传、URL 替换、重新打包和 HTML 导出。
5. 检索服务器代码，确认没有面向客户端的资源服务器直传、处理后 `.card` 提交或本地端发布提交契约。

## 期望行为

1. 官方本地上传器成为正式一等发布客户端，而不是网页上传接口的旁路调用。
2. 社区服务器提供发布会话接口，负责身份鉴权、权限、配额、资源归属前缀和上传目标签发。
3. 本地上传器使用可撤销、限时、限范围的正式机制把卡片内部资源直传资源服务器，不暴露长期对象存储密钥。
4. 本地上传器通过 Host / SDK 正式能力完成卡片解包、资源 URL 替换和重新打包，产出处理后的 `.card`。
5. 本地上传器把处理后的 `.card` 提交给社区服务器；为减轻社区带宽，处理后 `.card` 内不应再包含已外置的大体积资源。
6. 社区服务器接收处理完成后的 `.card`，执行结构校验、对象归属校验、数据库登记、公开入口生成和必要的安全审计。
7. 本地上传器阶段不执行 HTML / 封面 HTML 转换；后续如果查看链路、搜索索引或静态预览仍需要转换，由社区服务器在需要时转换。
8. 对于网页端上传，可以继续保留服务端处理链路作为网页轻量上传模式，但不能把它作为官方本地上传器的目标架构。

## 暂行处理

当前先登记工单并冻结问题边界。

在正式契约落地前：

- 不把现有 `/api/v1/upload/card` 描述为“支持本地端处理后发布”的最终链路；
- 不在本地上传器中保存对象存储永久密钥；
- 不绕过社区服务器数据库登记和权限校验直接写资源服务器；
- 后续实现前需要先同步更新生态共用技术文档中的社区平台 API 契约、本地上传器 API 专章、对象存储直传安全边界和状态机。
