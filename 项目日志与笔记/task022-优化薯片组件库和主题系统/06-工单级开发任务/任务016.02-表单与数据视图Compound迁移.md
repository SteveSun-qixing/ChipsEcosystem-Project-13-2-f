# 任务016.02：表单与数据视图 Compound 迁移

## 1. 任务目标

把 `Form / DataGrid / Tree` 迁移为正式 Compound API，收口表单字段、数据表格和树结构的 slot 规则。

## 2. 父任务

- `任务016-组件库复杂组件Compound迁移.md`
- 对应阶段任务：`05-开发任务方案/任务09-复杂组件Compound-API与样式契约.md`

## 3. 涉及项目

- `Chips-ComponentLibrary/packages/components`
- `Chips-ComponentLibrary/packages/theme-contracts`
- `Chips-Host/src/renderer/declarative-ui`
- `Chips-Host/tests/unit`
- `生态共用技术文档/组件库`

## 4. 开发内容

1. 为 `Form` 建立 `Root / Section / Field / Label / Control / Error / Hint` Compound API，并与既有 `FormField / FormGroup` 职责边界对齐。
2. 为 `DataGrid` 建立 `Root / Toolbar / Header / Row / Cell / Pagination` Compound API。
3. 为 `Tree` 建立 `Root / Item / Branch / Leaf / Disclosure` Compound API。
4. 补齐 TypeScript 声明、组件测试、a11y 规则、component contract 和公共文档。
5. 补齐 Host L8 `StandardCompoundSlotSchemas` 中本批组件对应 slot schema 与诊断测试。

## 5. 验收标准

- 表单、表格和树的 slot 必填/单例/重复规则明确，L8 能输出结构化诊断。
- `Form` 不把业务校验逻辑写入组件库，只提供字段结构、ARIA 关联和状态挂点。
- `DataGrid` 与 `Tree` 保持数据模型和 Compound slot 模式可组合，不把应用业务渲染写死。
- contract 覆盖本批新增或调整的公开 parts。
