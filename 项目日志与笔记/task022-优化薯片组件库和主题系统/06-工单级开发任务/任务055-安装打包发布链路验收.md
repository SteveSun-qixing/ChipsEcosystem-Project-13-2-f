# 任务055：安装打包发布链路验收

## 1. 任务目标

打通新框架重构后的 Host、五类插件、主题包、工作区、`.cpk`、`.card`、`.box` 和安装器发布链路，确保开发态、用户态、发布态一致运行。

## 2. 对应阶段任务

- `05-开发任务方案/任务28-安装打包发布与工作区迁移链路.md`

## 3. 涉及项目

- `Chips-Host`
- `Chips-SDK`
- `Chips-Scaffold/*`
- `Chips-BaseCardPlugin/*`
- `Chips-BoxLayoutPlugin/*`
- `Chips-ModulePlugin/*`
- `ThemePack/*`
- `release-artifacts/`

## 4. 开发内容

1. 重新核对 CPK 格式、Manifest 规范、打包与安装路径手册、Host CLI 和 chipsdev CLI。
2. 验证五类插件均可 build、validate、package，并安装到开发工作区。
3. 验证主题包可安装、启用、应用、切换和 contract 校验。
4. 验证应用插件系统快捷方式、文件关联、launchContext 和卸载清理。
5. 验证模块插件按需加载、能力发现、调用、job、取消和卸载。
6. 验证 `.card` 和 `.box` 在安装态 Host 中可打开、渲染、编辑、保存、导出。
7. 生成打包报告、安装报告、工作区迁移报告和发布阻断清单。

## 5. 验收标准

- 不只验证源码开发态，必须验证已安装副本运行态。
- `.chips-host-dev` 不被当作终端用户运行目录。
- 五类插件均有正式打包和安装验收记录。
- 发布阻断问题全部登记为工单。
