# 任务057：全生态最终质量门禁

## 1. 任务目标

在所有底座、SDK、组件库、主题、脚手架、应用插件、卡片插件、布局插件、模块插件、社区平台和真实素材回归完成后，执行最终质量门禁，判断是否具备第一版发布条件。

## 2. 对应阶段任务

- `05-开发任务方案/任务30-最终全生态质量门禁与发布验收.md`

## 3. 涉及项目

- 全生态工作区。

## 4. 开发内容

1. 汇总所有任务的验证结果、失败项、阻断项、性能结果和文档状态。
2. 执行根工作区、Host、SDK、组件库、主题包、脚手架、应用插件、卡片插件、布局插件、模块插件的正式脚本。
3. 执行社区平台 build/lint/test。
4. 执行安装打包验收和真实素材回归。
5. 执行禁用口径扫描：临时实现、TODO、硬编码主题、直连 Host、跨服务 import、未走 i18n。
6. 生成最终质量门禁报告：可发布、条件发布或不可发布。
7. 对所有 P0/P1 问题创建或补充工单。

## 5. 验收标准

- P0/P1 问题不得进入可发布结论。
- 所有正式脚本通过或有明确环境限制说明。
- 架构红线扫描无未解释违规。
- 质量门禁报告能支撑第一版发布决策。

## 6. 验证命令

```bash
npm run verify:workspace

cd Chips-Host && npm run build && npm test
cd ../Chips-SDK && npm test
cd ../Chips-ComponentLibrary && npm run quality:gate
```

## 7. 注意事项

- 不为了发布通过而降低质量门禁。
- 本任务执行前必须重新核对所有 package 脚本和 manifest，不能使用过期命令清单。
