# 任务059.06：功能模块插件开发技能 vNext 创建与更新

## 1. 任务目标

创建或更新 `chips-module-plugin-dev` 技能，使 Host 托管无界面模块插件的开发、迁移、能力契约、调用治理和验证基于任务026最终口径。

## 2. 范围

- 功能模块插件开发技能目录
- `生态共用技术文档/插件开发/05-模块插件开发.md`
- `生态共用技术文档/协议与契约/06-模块能力契约.md`
- `Chips-Scaffold/chips-scaffold-module`
- `Chips-ModulePlugin/*`

## 3. 开发内容

1. 审查旧模块相关技能，移除应用窗口化、跨目录 import 或直接源码调用口径。
2. 写清 `module.provides / module.consumes`、能力版本、权限、错误码、同步返回、异步 job 和取消。
3. 写清 `chipsdev create module`、`npm run verify`、`chipsdev package`、安装启用和 `chipsdev module invoke`。
4. 写清模块插件与应用插件、Host、SDK、Bridge 的边界。

## 4. 验收标准

- 技能能指导创建可被 Host 正式发现和调用的模块插件。
- 技能不会把 Host 运行时主实现复制进 SDK 或插件。
- 技能与任务026最终模板、公共文档和真实 e2e 一致。

## 5. 注意事项

- 依赖任务026全部完成。
- 现有五个模块插件业务迁移仍按任务046到任务050执行。
