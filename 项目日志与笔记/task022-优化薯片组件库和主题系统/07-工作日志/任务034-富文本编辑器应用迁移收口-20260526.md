# 任务034：富文本编辑器应用迁移收口

## 本阶段目标

完成 `任务034.01`、`任务034.02`、`任务034.03` 的代码、文档与验证收口，使 `Chips-RichTextEditor` 进入应用插件 vNext 根结构，并保持现有单文档富文本写作功能、交互和 `.card` 数据模型。

## 主要改动

1. 应用入口迁移：
   - `src/App.tsx` 改为标准 re-export；
   - 新增/接入 `AppRoot / AppProviders / AppRuntimeProvider / AppShell`；
   - `RichTextEditorScene` 改为消费 `useAppRuntime()`，不再自行创建 SDK client 或直接订阅 Bridge。
2. 命令系统接入：
   - 新增 `src/commands/rich-text-editor-commands.ts` 与 `useRichTextEditorCommands.ts`；
   - 注册新建、打开、保存、另存为、导出、预览、当前信息、撤销、重做、查找、格式；
   - 右上角菜单消费 command view 并通过 `client.command.invoke()` 触发；
   - `manifest.yaml` 补齐 command 与相关运行时权限。
3. 富文本 `.card` 数据链路：
   - `RichTextBaseCardConfig.card_type` 新写入值统一为 `base.richtext`；
   - 保存配置补齐 `markdown_capabilities`，与当前 `richtext-BCP` schema 对齐；
   - 资源收集同时覆盖文件正文与内联 Markdown 中的相对资源引用。
   - `manifest.resources` 从正式配置引用的资源路径生成，并通过文件状态补齐大小与 MIME，避免依赖不同 Host 文件列表递归形态。
4. 主题、多语言、A11y：
   - 命令 metadata 只写 `titleKey / descriptionKey / ariaLabelKey`；
   - 补齐 `zh-CN/en-US` 命令文案、状态提示和菜单分组；
   - 菜单按钮、菜单项、信息弹窗继续保留可访问名称与 Esc 关闭路径；
   - 主题状态由 `ChipsEnvironmentProvider / ChipsThemeProvider / useAppRuntime()` 承接。
5. 归档旧入口：
   - 将旧 `src/hooks/useChipsBridge.ts` 与 `src/hooks/useChipsClient.ts` 移入 `Chips-RichTextEditor/归档/20260526-任务034旧运行时hooks/`；
   - `src/` 与测试中不再保留私有 Bridge / SDK client 初始化入口。
6. 文档同步：
   - 更新 `Chips-RichTextEditor/README.md`；
   - 更新 `技术手册/01-系统概览与依赖边界.md`；
   - 更新 `技术手册/02-编辑会话与持久化方案.md`；
   - 更新 `技术手册/03-界面壳、主题与多语言接入.md`；
   - 更新 `技术手册/04-测试与验证手册.md`；
   - 更新公共文件格式规范中的富文本基础卡片配置 schema。
