# 分报告 01：组件库工程与质量门禁问题

> 调查日期：2026-08-06
> 调查对象：`Chips-ComponentLibrary`（根工程、packages、scripts、tests）
> 关键结论：所有门禁（verify/quality:gate/release:check）全部"通过"，但 `npx tsc --noEmit` 有 3886 个类型错误；typecheck 只是 `node --check`、lint 不跑 ESLint、perf 不测渲染、coverage 不是代码覆盖率。

## 1. 组件源码形态：16999 行单文件

- `packages/components/src/index.js` = **16999 行 / 474730 字节**，内含全部约 70 个组件与全部工具函数；`layout-primitives.js` 989 行。**没有任何按组件的源码文件拆分，没有 TS 源码**（同目录只有 index.js/index.d.ts/layout-primitives.js/layout-primitives.d.ts）。
- git 历史确认：该 JS 文件从仓库最早提交就存在，从未存在独立 TS 源码；index.d.ts 与 index.js 同 mtime（2026-05-29），为手写维护（无生成头注释）。
- 问题：
  1. 无法进行有效的按组件 code review、无法定位变更影响面；
  2. `package.json` main/exports 只有 "." 单一入口，无子路径导出、无 sideEffects 声明，消费方只能整体加载全部组件代码（无 tree-shaking）；
  3. **d.ts 与实现清单不一致**：JS 120 个命名导出 vs d.ts 105 个声明，`resolveSystemMessageQueue`（index.js:3448 导出）在 d.ts 中完全缺失；
  4. `@chips/primitives`（对外包）**连 index.d.ts 都没有**，package.json 无 types/exports.types，违反技术文档/29:48-50"对外包必须通过 types/exports.types 暴露正式声明入口"；
  5. `@chips/tokens` 同样无 types/exports（main 直接指向 tokens/sys.json）。

## 3. 真实 tsc --noEmit 错误统计（实测）

命令：`npx tsc -p tsconfig.json --noEmit`（tsconfig 已启用 checkJs + strict）

- **错误总数：3886**
- 错误码分布（Top）：TS2339 (2247)、TS7006 (1076)、TS7053 (143)、TS18047 (69)、TS18046 (51)、TS7005 (48)、TS7031 (40)、TS7034 (38)、TS2345 (35)、TS2349 (32)、TS2769 (28)、TS2322 (22)
- 按文件分布（Top）：`components/src/index.js` **2317**、`hooks/src/index.js` 292、`testing/src/index.js` 196、`layout-primitives.js` 171、`components/tests/index.test.mjs` 156、`a11y/src/index.js` 115、`theme-contracts/src/validator.js` 108
- 性质：TS2339 是 checkJs 下对 `{}`/any 对象访问属性（大量 props 解构与事件对象）；TS7006 是参数隐式 any。

**关键对照**：quality-gate-latest.json 显示 passed，而同一仓库用官方 tsconfig 跑 tsc 报 3886 错误。"门禁绿、类型红"。

## 4. 冻结技术栈零依赖

- 宣称：README.md:5 "React + Ark UI + Style Dictionary + Tamagui (Core)"；技术文档/01:14-18、/03（Ark-UI二次封装规范全文）、/04（Tamagui-Core集成规范全文）、/05（Style Dictionary流水线）、/12:11；生态共用技术文档/组件库/01:9 同样宣称。
- 实际：根与所有子包 package.json、package-lock.json、node_modules 中 **不存在** `@ark-ui/*`、`@zag-js/*`、`@tamagui/*`、`style-dictionary` 任何一条。
- 真相：
  - `packages/components/src/index.js` 全部为**自研** React.forwardRef 组件 + 自研 `resolveInteractiveState`/`interactiveStateReducer`（index.js:2449,2477）+ 自研键盘逻辑；
  - `packages/primitives/src/index.js:114` `mapArkPrimitiveProps` 只是**借用 "Ark" 命名的自研 helpers**，无任何 ark 依赖 import；
  - `packages/adapters/tamagui-core/src/index.js` 是自研 token resolver（约146行），无 `@tamagui/core` import；README 宣称 "Token mapping helpers for Tamagui Core integration"，实际 integration 不存在；
  - `build-tokens.mjs` + `token-utils.js`（194行）为手写 token 流水线，非 Style Dictionary。
- 影响：生态共用文档对外宣称的技术基线失实，影响所有消费方选型判断。工单094 已登记，状态待处理。

## 5. 测试覆盖真相

- 20 个测试文件、256 个测试全过（node:test + node:assert/strict；jsdom 28.1.0 为 devDependency）；
- 真实渲染 React 的仅两处：keyboard-a11y.test.mjs（6 个用例，createRoot+act+JSDOM 真实挂载并 dispatchEvent）、hooks/tests（自研 renderHook 约 10 个用例）；
- 其余 96 个 index.test.mjs 用例主体是 `renderToStaticMarkup`（SSR 静态字符串）+ `new JSDOM(html)` 解析静态 HTML 断言 data 属性；
- **无任何浏览器测试**（无 playwright/puppeteer）、无视觉回归、无跨主题真实浏览器验收；
- 测试缺口：Dialog focus trap 键盘序列、SplitPane pointer capture 与卸载清理、跨主题真实渲染、语言切换 DOM 生效、DataGrid 列交互等无测试。
